# FAQ продукта

## Сессия отозвана после смены пароля

После успешной смены пароля все ранее созданные пользовательские сессии
отзываются. Ошибка `session_revoked` означает, что клиент пытается продолжить
работу со старой сессией. Пользователю нужно выйти из приложения или браузера,
удалить старую сессию и войти снова с новым паролем. Повторная смена пароля для
этого не требуется.

Если новый вход также завершается ошибкой, оператор должен проверить время
смены пароля, код последней ошибки и передать тикет второй линии поддержки.

## Аккаунт заблокирован

После пяти неуспешных попыток авторизации аккаунт временно блокируется на 30
минут. Ошибка `account_locked` не устраняется повторными попытками входа:
пользователю следует дождаться окончания блокировки или запросить у оператора
безопасную разблокировку после проверки владельца аккаунта.

Для входа через Google нужно продолжать использовать кнопку «Войти через
Google». Пароль продукта не заменяет учётные данные внешнего провайдера.

## Многофакторная авторизация

Если у пользователя включена многофакторная авторизация, после проверки пароля
система запрашивает одноразовый код. При потере доступа к приложению кодов
оператор не должен отключать MFA без проверки владельца аккаунта. Тикет нужно
передать в процедуру восстановления доступа.

## Эскалация обращения

Тикет передаётся второй линии, если инструкции из FAQ выполнены, но ошибка
повторяется, диагностический код отсутствует или состояние аккаунта
противоречит наблюдаемой ошибке. В эскалации указываются идентификатор тикета,
категория, код ошибки, клиент и уже выполненные безопасные действия.
