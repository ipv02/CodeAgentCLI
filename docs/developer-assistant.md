# Ассистент разработчика

CodeAgentCLI предоставляет проектный режим помощи через команду `/help QUESTION`.
Он сочетает локальный поиск по документации и read-only Git-контекст, полученный
через встроенный Pipeline MCP server.

## Архитектура

- `code_agent_cli/main.py` отвечает за CLI, slash-команды и терминальный вывод.
- `code_agent_cli/pipeline_mcp_server.py` публикует инструменты Pipeline MCP.
- `code_agent_cli/pipeline_service.py` содержит реализацию pipeline, индексации и
  безопасных проектных инструментов.
- `code_agent_cli/document_index.py` читает документы, создает чанки и хранит
  embeddings в SQLite.
- `code_agent_cli/rag_service.py` выполняет retrieval, фильтрацию, rerank и
  формирует ответы с проверенными источниками и цитатами.

Индекс по умолчанию хранится в
`~/.code-agent-cli/pipeline/document_index.db`. Embeddings создаются локально
через Ollama и модель `nomic-embed-text`.

## Подготовка

Запустите Ollama, загрузите embedding-модель, затем в интерактивном агенте
выполните:

```text
/mcp init-pipeline
/mcp index-project-docs .
```

Специализированная индексация включает корневые файлы `README*`, папку `docs/`
и, если она существует, `project/docs/`. Обычная `/mcp index-docs PATH`
по-прежнему индексирует все поддерживаемые документы и исходники.

При аргументе `.` агент сначала использует текущий корень проекта, а при запуске
editable-версии из другого каталога находит корень CodeAgentCLI автоматически.
Явный путь или `CODE_AGENT_PROJECT_DIR` можно использовать для другого проекта.

## Использование

```text
/help Как устроен проект?
/help Где находится SQLite-индекс документов?
/help Какая сейчас Git-ветка?
```

Голая команда `/help` сохраняет прежнее поведение и показывает справку CLI.
Git-инструмент выполняет только команды чтения и не изменяет рабочее дерево.

По умолчанию генерация ответа использует настроенный DeepSeek API, поэтому
найденные фрагменты документации передаются внешней модели. Для полностью
локальной работы с проектной документацией используйте
`agent --local-context-chat`, который выполняет retrieval и генерацию через
Ollama без `DEEPSEEK_API_KEY`.

Если релевантный контекст не найден, ассистент отвечает «Не знаю» и предлагает
уточнить вопрос или переиндексировать документацию. Источники и цитаты строятся
из найденных чанков, а не из текста модели.
